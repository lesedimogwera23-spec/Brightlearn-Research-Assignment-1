📚 What I Learned

One of the main lessons from this assignment is that Data Analytics involves much more than simply creating charts or calculating numbers.

A data professional needs to understand how data is collected, stored, cleaned, analysed, visualised and communicated.

I also learned that technology should be used responsibly. Concepts such as data privacy, data ethics, governance and AI bias are important because poor use of data can negatively affect individuals and organisations.

💡 Key Takeaways

Some of my key takeaways from this assignment include:

Data is valuable when it can be turned into useful information and insights.
APIs allow different software systems to communicate with each other.
Python is an important tool for data analysis and AI.
Git and GitHub help professionals track and manage their work.
AI can be powerful, but its results still need to be evaluated by humans.
Data privacy and ethics are important when working with people's information.
Different data careers have different responsibilities, but they often work together.
Continuous learning is important because the data and AI field continues to evolve.
